# klar evals

Studies of how AI agents use klar. Each study is pre-registered: its
hypotheses, decision rule and round plans were committed before the data
they're tested against, so the history of each directory is part of the
evidence. Cite a study by its release tag, not by branch.

| Study | Question | Status |
|---|---|---|
| [skill-vs-playbook](./skill-vs-playbook/) | Does shipping agent guidance as a skill instead of a `CLAUDE.md` pointer change whether agents read it and use klar correctly? | Complete: 222 trials, Haiku 4.5 + Sonnet 5.5 |

Nothing under `evals/` ships in the npm package.
